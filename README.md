## 🔍 Overview

**CITYWISE-AI** bridges the gap between complex urban data streams and actionable municipal planning. It provides city administrators and urban planners with real-time visualizations and predictive ML models for traffic density, energy load, waste management, and emergency response optimization.

---

## 🚀 Key Features

- 📊 **Real-Time Urban Analytics**: Dynamic dashboard showing traffic congestion, air quality (AQI), and energy utilization.
- 🤖 **AI Resource Recommender**: Machine learning models suggesting optimal deployment of public transport and emergency services.
- 🗺️ **GIS Map Visualization**: Interactive spatial mapping for civic infrastructure and utility monitoring.
- 📱 **Responsive Dark-Glass UI**: Fast, responsive web application hosted on Vercel edge networks.

---

## 🛠️ Tech Stack

- **Frontend**: React.js, Tailwind CSS, Chart.js, Leaflet / Mapbox GIS
- **Backend**: Node.js, Express, REST APIs
- **Deployment**: Vercel Edge Platform
